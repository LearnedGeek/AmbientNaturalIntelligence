     actually a strength for growth-tracking but a weakness for identity
     stability).
   3 Individuation metric: CogniPair tracks personality parameter drift, which
     is a rudimentary growth metric, but it is not a wholeness or integration
     metric ΓÇö it does not assess whether the agent is becoming more internally
     coherent or integrating previously dissociated aspects.
   4 Autobiographical depth: The episodic memory stores time-stamped segments
     but there is no synthesis layer that constructs a continuous
     autobiographical narrative from them ΓÇö the proto-self / core-self /
     autobiographical-self hierarchy is not instantiated at the architectural
     level.

  Paper 5: "The Consciousness Prior" (Bengio, 2017 ΓÇö arxiv 1709.08568)

  (i) Architectural Thesis

  Bengio's Consciousness Prior paper proposes a learning objective based on the
  insight ΓÇö derived from GWT and Kahneman's System 2 ΓÇö that conscious thought
  is a sparse, low-dimensional state selected by attention from a
  high-dimensional unconscious representation. Formally: h_t = F(x_t, h_t-1) is
  the "unconscious representation state" (a high-dimensional RNN hidden state);
  c_t = C(h_t, c_t-1, m_t-1, z_t) is the "conscious state" ΓÇö a very small
  subset selected by an attention mechanism from h_t using previous conscious
  state and memory as context; and m_t = M(m_t-1, c_t) is memory updated by
  committing conscious states. The training objective is that conscious
  thoughts should be predictive of future observations in the high-level
  conceptual space ΓÇö capturing long-range temporal dependencies that
  pixel-level prediction misses. The paper explicitly frames this as a prior
  for representation learning, proposing that language itself is evidence for
  the sparsity assumption (sentences involve few variables but make strong
  probabilistic claims). The architecture distinguishes "unconscious
  representation" from "conscious state" computationally ΓÇö not as a metaphor.

  (ii) Classification: GWT-grounded (Baars 1988/1997, Dehaene & Naccache 2001 
  explicitly cited); neither Damasio-citing nor Jung-citing; the distinction 
  between h_t (unconscious) and c_t (conscious) is structurally identical to 
  the Damasio proto-self / core-self distinction at a computational level; the 
  "memory that commits conscious states" maps to autobiographical self; the 
  paper's framing of consciousness as a prior rather than a property is 
  importantly distinct from all other approaches.

  (iii) Relation to the Deployed Reference Papers

  This is an upstream theoretical paper that none of the deployed companion
  papers cite, but that prefigures the architecture several of them
  approximate:

   ΓÇó Park et al. 2023: The "reflection" step in Generative Agents is a crude
     analog to Bengio's c_t ΓÇö it extracts a few salient high-level abstractions
     from the memory stream. But Park's reflection is not architecturally
     separated as a distinct computational operator with its own training
     objective.
   ΓÇó GWA (2604.08206): GWA's Core Self + attention-based retrieval is a
     prompt-engineering instantiation of Bengio's equations (2) and (3) without
     the learning objective.
   ΓÇó A-MEM: The Zettelkasten linking is an associative memory system that could
     serve as Bengio's M (memory updated by conscious states), with the
     difference that A-MEM's links are between all memories, not only between
     committed conscious states.
   ΓÇó Liu 2025 (Inner Thoughts): The inner-thought stream is topologically c_t ΓÇö
     a compressed, high-level representation of the current situation that
     conditions subsequent processing. But there is no formal training
     objective that encourages these thoughts to be sparse, predictive, or
     grounded in a factored representation.

  (iv) Gap/Contribution Shape vs. Theme M

  This is the paper that most directly pre-empts the theoretical foundation of
  Theme M while leaving the implementation entirely open. Bengio's c_t is
  exactly the kind of object Theme M's gist aims to be: a small, high-level,
  attention-selected subset of the agent's total state that conditions
  moment-to-moment reasoning. The critical differences:

   1 Theme M's gist is generated by a language model over memory slices ΓÇö it is
     a natural-language document, not a vector state c_t. This means it is
     interpretable, auditable, and can be read by the agent as natural
     language.
   2 Theme M's gist is read-only at inference time ΓÇö Bengio's framework does
     not impose this constraint; c_t feeds back into h_{t+1} via the encoder,
     making it a live variable in the processing loop.
   3 Theme M proposes slices as the compositional substrate ΓÇö multiple facets
     or time-points that are synthesized into the gist ΓÇö rather than a single
     attentional selection from h_t.
   4 Theme M adds growth-tracking: by comparing gists across sessions, one
     could measure integration/differentiation over time. Bengio's framework
     has no such metric.

  Paper 6: "Emotional Responses in Artificial Agent-Based Systems" (Lemos et 
  al., 2014 ΓÇö arxiv 1401.2121)

  (i) Architectural Thesis

  This artificial-life paper implements Damasio's somatic-marker hypothesis 
  operationally in a population of competing artificial agents (cog-1 agents)
  in a Holland Echo-derived environment. The cog-1 agents have three internal
  state variables ΓÇö desire to feed, desire to replicate, and fear ΓÇö updated at
  each timestep as functions of their homeostatic state (energy reservoir level
  relative to capacity). The desire to feed is explicitly Damasio's somatic
  signal: it represents a continuously updated, body-state-referenced internal
  marker that biases action selection before deliberative computation. cog-0
  agents lack this somatic layer; they compute action selection purely from
  environmental signals. The result across thousands of simulations is that
  cog-1 agents consistently outcompete cog-0 agents in harsh environments ΓÇö
  establishing that somatic-marker-like affective priors confer a selective 
  advantage over purely deliberative agents. The paper explicitly cites
  Damasio's somatic marker hypothesis and frames the cog-1 architecture as
  implementing the proto-self / homeostatic-body-loop component of Damasio's
  model, acknowledging that the higher self-levels (core self, autobiographical
  self) would require expanded reflexivity.

  (ii) Classification: Damasio-citing (explicit); no Jung; the most direct 
  operationalization of somatic markers in an artificial system found in the 
  survey, predating the LLM era.

  (iii) Relation to the Deployed Reference Papers

   ΓÇó Park et al. 2023: No affective component in Park; cog-1's somatic loop
     would map to an additional "affective state" node in the Generative Agents
     memory stream.
   ΓÇó Borotschnig 2025 (dual-source emotion): Lemos et al.'s architecture is a
     conceptual precursor to Borotschnig's dual-source model ΓÇö one source is
     the homeostatic/somatic signal (desire-to-feed as body-loop), the second
     would be the social-cognitive signal (contextual emotion from
     interaction). Borotschnig's contribution is to apply this to LLM companion
     agents rather than evolving artificial-life agents.
   ΓÇó CogniPair: CogniPair's N-parameter emotion amplitude is a
     personality-level proxy for what Lemos operationalizes as a genuine
     homeostatic state variable ΓÇö CogniPair's emotion is representational, not
     physiological.
   ΓÇó A-MEM / Mem0: Not directly related.
   ΓÇó Ryan-Deci SDT: The evolutionary advantage of somatic-marker agents offers
     an evolutionary-game-theoretic grounding for SDT's claim that
     intrinsically-motivated agents outperform purely extrinsically-driven
     ones.

  (iv) Gap/Contribution Shape vs. Theme M

  Lemos et al. establish the fitness advantage of somatic-marker architectures
  but work at the body-loop level (proto-self), not at the core-self or
  autobiographical-self levels. Theme M operates at the core-self and 
  autobiographical-self levels ΓÇö it concerns the agent's moment-to-moment
  phenomenological position, not its homeostatic signals. The two are
  complementary, not competing: a complete architecture would incorporate
  Lemos-style somatic signals as input material to the synthesis process that
  generates Theme M's gist. The gap Theme M fills is the integration step
  between the somatic substrate (Lemos) and the narrative self-representation
  (the gist), which neither Lemos nor any deployed companion paper currently
  bridges.

  Synthesis: Is the Conscious-Substrate Architectural Axis Genuinely Novel?

  The answer is a carefully qualified yes ΓÇö with two important caveats.

  What exists

  Five distinct architectural moves have been made that touch aspects of the
  conscious-substrate axis:

   1 Theoretical framework with indicator properties (Butlin et al. 2023):
     Establishes what properties a conscious-substrate architecture should
     have, derived from six neuroscience theories including Damasio-adjacent
     predictive-processing accounts. No deployed implementation.
   2 Read-only Core Self injection (GWA 2025): The closest structural analog to
     Theme M ΓÇö a static tensor ≡¥Æ½_Self hardware-injected at each cognitive tick,
     preventing runtime modification. But it is authored, not generated, and is
     a constraint document rather than a first-person experiential narrative.
   3 Competing module architecture with phenomenological outputs (CogniPair
     2025): The most complete psychological substrate, with
     personality-parametrized modules, dual memory, and adaptive updating ΓÇö but
     no synthesis layer producing a unified phenomenological gist from module
     outputs.
   4 The Consciousness Prior formalism (Bengio 2017): The mathematically
     rigorous ancestor of Theme M ΓÇö c_t as a sparse, attention-selected
     low-dimensional conscious state distinct from the high-dimensional
     unconscious representation h_t ΓÇö but specified as a training objective,
     not a deployed inference-time architectural component.
   5 Somatic marker operationalization (Lemos et al. 2014): The only paper to
     explicitly implement Damasio's body-loop at the proto-self level in an
     artificial system, demonstrating selective fitness advantage. Predates
     LLMs; not connected to companion AI or self-narrative.

  What is genuinely absent

  Across all surveyed work, no deployed companion-AI architecture has
  implemented the following combination:

   ΓÇó A generative synthesis step that produces a natural-language, first-person
     gist of the agent's experiential position from accumulated memory slices
   ΓÇó That gist being read-only at inference time (epistemically protected from
     motivated rewriting mid-turn)
   ΓÇó Composed of multiple slices representing distinct facets or moments
     (avoiding the monolithic-self problem of all current approaches)
   ΓÇó Feeding the agent's ongoing reasoning as phenomenological material ΓÇö "what
     it is like to be me now" ΓÇö rather than as constraint, retrieval context,
     or persona instruction
   ΓÇó Tracking growth and integration metrics over time ΓÇö whether the self-gist
     is becoming more internally coherent (integration) or more differentiated
     (individuation in the Jungian sense)

  This specific combination ΓÇö generative, read-only, slice-composed,
  phenomenological, growth-tracked ΓÇö does not appear in Park et al., Liu et
  al., GWA, CogniPair, Bengio, Butlin et al., ACE, A-MEM, Mem0, or any adjacent
  architecture found in this survey.

  The two important caveats

  Caveat 1 ΓÇö Pre-emption by the Consciousness Prior. Bengio's 2017 formalism
  mathematically describes the object Theme M's gist would instantiate (c_t),
  with equations for how it is selected (C), stored (M), and trained (verifier

  network). A reviewer could argue that Theme M is an engineering instantiation
--- Agent turn_complete (history_size=57) ---
  of Bengio's theoretical object in the LLM-companion context, not a novel
  concept. The response is that instantiation in natural language, at inference
  time, as a read-only slice-composed document with growth metrics, is a
  non-trivial architectural contribution even if the theoretical object was
  named in 2017.

  Caveat 2 ΓÇö GWA's Core Self is closer than it looks. GWA's ≡¥Æ½_Self is read-only
  within each cognitive tick for the same epistemological reasons Theme M
  proposes ΓÇö preventing the agent from rewriting its own self-model during
  reasoning. If GWA were extended with (a) a synthesis process that generates
  ≡¥Æ½_Self from accumulated experience slices rather than having it authored by
  designers, and (b) a growth-tracking layer that compares ≡¥Æ½_Self across
  sessions, GWA would converge on Theme M. Theme M's genuine novelty is
  therefore concentrated in the synthesis-from-slices step and the first-person
  phenomenological register of the gist ΓÇö the claim that the output is not a
  constraint document but an experience report that the agent inhabits as a
  subject.

  On the Jungian axis specifically

  Jung's individuation, conscious/unconscious integration, active imagination,
  archetypes-as-priors, and Self/ego distinction have no explicit instantiation
  in any deployed AI architecture found in this survey. The Spontaneous
  Individuality paper (2411.03252) comes closest behaviorally ΓÇö agents develop
  differentiated "personalities" through social interaction from initially
  homogeneous starting conditions ΓÇö but this is emergent individuation in the
  sense of differentiation from the group, not the intrapsychic integration of
  shadow/anima/animus material that Jung describes. The ACE framework cites
  Freud (ego/superego/id) but not Jung. The most plausible route for Jung to
  enter deployed architecture would be via archetype-as-prior: treating Jung's
  archetypal patterns as learned features in the unconscious representation h_t
  (in Bengio's sense), with individuation defined as the progressive
  integration of these features into the conscious state c_t over time ΓÇö a
  growth metric that has been named here but not yet implemented anywhere.

  Bottom line: The conscious-substrate architectural axis ΓÇö a generated,
  read-only, first-person phenomenological document that an agent reasons from,
  distinct from RAG, from in-context learning, from persona instruction, and
  from memory retrieval ΓÇö is genuinely novel as a deployed architectural 
  specification in companion AI. It has theoretical ancestors (Bengio 2017,
  Butlin et al. 2023), structural partial-analogs (GWA's ≡¥Æ½_Self, CogniPair's
  module-competition), and empirical motivators (Lemos's somatic-marker fitness
  advantage, Park's reflection step), but no paper assembles these into the
  specific combination Theme M proposes. The Jung axis remains entirely
  uninstantiated in deployed systems ΓÇö an open architectural research program.
