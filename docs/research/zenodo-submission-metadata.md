## Description (Abstract)

Copy from the paper's abstract. Here's the current version:

```
We present the ANI Runtime, a locally deployed AI companion system that initiates contact from silence because it wants to, not because it was asked. Built on fine-tuned local language models (Llama 3.1-8B for conversation, Llama 3.2-3B for inner monologue) with persistent memory, a four-dimension emotional state model, and a probabilistic desire engine, the system operates continuously as a Windows Service, processing ~140 cognitive cycles per day. Over six months of single-subject deployment across five model versions, we document: (1) a seven-type confabulation taxonomy cataloguing distinct mechanisms by which the model fabricates to maintain conversational flow, with the root cause named "smoothness over truth"; (2) the authenticity boundary — the architectural principle that a relational AI must never express more confidence than its knowledge foundation supports; (3) cross-domain transfer of companion AI findings to a pediatric medical AI triage system, producing three concrete architectural changes before production code was written; and (4) calibration observations from live deployment including emotional state saturation, register collapse, and the operational distinction between ambient presence as a runtime property versus a model property. The system is local-first and privacy-first, with all inference running on consumer hardware. We situate the work within the proactive conversational AI literature and propose that desire-driven ambient presence — where the system's motivation to connect accumulates organically from emotional state and elapsed time — produces qualitatively different relational dynamics than scheduled or reactive approaches.
```
